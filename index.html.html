발행일:

GitHub Pages 웹사이트 무료 공유 방법

서버 비용 없이 5분 만에 선생님 전용 진학 웹 대시보드 만들기

1

HTML 파일 저장하기

이 페이지 코드 전체를 복사하여 컴퓨터에 index.html 이름으로 저장합니다.

2

GitHub Repository 생성

GitHub.com 로그인 후 오른쪽 상단 + 버튼 > New repository를 클릭합니다.
Repository name에 admission-dashboard 입력 후 Public으로 선택하고 Create 버튼을 누릅니다.

3

index.html 업로드

생성된 저장소 페이지에서 uploading an existing file 링크를 눌러 저장해 둔 index.html 파일을 올리고 Commit changes를 클릭합니다.

4

GitHub Pages 활성화

상단 메뉴 Settings > 좌측 Pages 선택 후,
Build and deployment의 Branch를 main (또는 master) 및 /(root)로 설정하고 Save를 클릭합니다.

완성된 무료 공유 웹 링크 생성!

약 1~2분 후 https://<아이디>.github.io/admission-dashboard/ 형식의 고유 웹사이트 주소가 자동 발급됩니다.
이 링크를 동료 교사 카톡방, 학교 메신저, 구글 사이트에 바로 전달하실 수 있습니다.
